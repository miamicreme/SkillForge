# Attribution

SkillForge is based on [`addyosmani/agent-skills`](https://github.com/addyosmani/agent-skills), which is licensed under the MIT License.

The upstream project provides the core engineering skill foundation: structured agent skills, development lifecycle commands, personas, references, validation scripts, and eval concepts.

SkillForge preserves that foundation and extends it with:

- productized workflow packs,
- higher-level recipes that compose multiple skills,
- business and consulting use cases,
- repo audit workflows,
- MVP build workflows,
- business operations automation workflows,
- SignalBrief research-to-delivery workflows,
- FrameBrief video-to-brief workflows.

## SkillForge Direction

SkillForge is intended to become a practical operating layer for disciplined AI agents. It is not positioned as a replacement for the upstream project. It is a downstream product and workflow layer that builds on the original idea while adding specialized packs, service-ready playbooks, and MiamiCreme delivery workflows.

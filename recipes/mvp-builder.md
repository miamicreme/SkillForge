# MVP Builder Recipe

Use this recipe when turning a product idea into a buildable MVP plan.

## Goal

Move from rough idea to clear MVP scope, technical plan, build slices, and launch checklist.

## Inputs

- Product idea
- Target user
- Primary problem
- Must-have workflow
- Existing assets or repo
- Timeline
- Budget and technical constraints

## Workflow

1. Define the user and problem.
2. Identify the smallest valuable workflow.
3. Write a clear product spec.
4. Break the build into thin vertical slices.
5. Define data model and integration boundaries.
6. Add test and quality gates.
7. Create the first launch checklist.

## Recommended Skills

- `idea-refine`
- `spec-driven-development`
- `planning-and-task-breakdown`
- `api-and-interface-design`
- `frontend-ui-engineering`
- `test-driven-development`
- `shipping-and-launch`

## Output Format

```md
# MVP Plan

## Product Thesis

## Target User

## Core Workflow

## MVP Scope

## Non-Goals

## Technical Architecture

## Build Slices

## Test Plan

## Launch Checklist
```

## Quality Gate

The MVP must be small enough to build, test, and demo. If the plan contains multiple products, split it before building.
